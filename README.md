## Featured projects

### 🏭 Predictive Digital Twin for Industrial Machines
> *Flagship research & deployment project · Manuscript authored*

A production-grade IIoT Digital Twin ecosystem solving the "Black Box" and "Cold Start" challenges in industrial predictive maintenance.

- Trained LSTM deep learning models on **NASA C-MAPSS** data — RMSE **14.38 cycles**, competitive with published research baselines
- Built a custom **EMA Monotonic Filter** to eliminate sensor noise during the cold-start buffering phase
- Integrated **real-time SHAP** to translate deep learning inferences into root-cause explanations for floor operators
- Architected a **sub-second latency microservices pipeline** over MQTT, synchronizing a live Webots 3D simulation, edge inference engine, and Flutter mobile dashboard
- Supports both **cloud and air-gapped** deployment environments

`Python` `TensorFlow` `Keras` `SHAP` `MQTT` `Flutter` `Dart` `Webots` `Edge AI` `Scikit-learn`

### 🛡️ HR Guardian — Attrition Prediction & AI Explanation Agent

An end-to-end ML system combining predictive analytics with GenAI for HR decision support.

- Engineered an **NLP-driven LangChain agent** that translates SHAP metrics into plain-language explanations for non-technical HR teams
- Achieved **high-recall attrition classification** on a labeled dataset of 1,400+ employee records
- Implemented a **custom probability threshold strategy** to maximize recall and ensure at-risk employees are flagged early
- Built with **Evidently AI** for model monitoring and bias mitigation

`Python` `XGBoost` `LangChain` `SHAP` `Evidently AI` `Streamlit`

End-to-end forecasting and inventory management system for automotive dealerships.

- Achieved **70% R²** accuracy for profit prediction using XGBoost + Prophet (aligned with industry benchmarks)
- Generated automated **24-month sales projections** with statistically validated confidence bounds
- Full-stack deployment: **FastAPI backend + React frontend + Docker**, with extensive EDA notebooks

`Python` `XGBoost` `Prophet` `FastAPI` `React` `Docker` `Time Series Analysis`
